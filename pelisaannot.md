# Ryhmän pelisäännöt

- Pidämme yhteyttä Discordissa.
- Vastaamme ryhmän viesteihin kohtuullisessa ajassa.
- Osallistumme sovittuihin tapaamisiin.
- Ilmoitamme ajoissa, jos emme pääse osallistumaan.
- Jokainen vastaa omista tehtävistään.
- Autamme muita ryhmän jäseniä tarvittaessa.
- Noudatamme eettisiä käytäntöjä

# Group rules

- We communicate using Discord
- We answer messages in a reasonable time 
- We participate in agreed-upon meetings
- In case of unavailability, we inform the rest of our teammates
- Everyone will do their part
- We will help eachother as needed
- We will follow general ethical practices
- Always inform other members if you start to do some changes to the project

# Technical rules

1. Commit messages:
Use descriptive commit messages in English (e.g., Add route for BibTeX export, Fix reference filtering by author).
2. Writing code:
Write clear and easy-to-read code following Pylint standards
